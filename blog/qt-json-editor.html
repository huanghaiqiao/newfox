Qt JSON 可视化编辑工具开发总结

2026.06开发

需求来源

标定工程师需要频繁编辑 JSON 格式的远程标定文件，传统的手工编辑效率低、易出错。需要一套可视化的编辑工具来提升工作效率和准确性。

核心功能

  • 一维/二维表格化编辑：将 JSON 结构解析为表格形式，支持单元格直接编辑
  • 搜索高亮：快速定位关键字段，匹配内容高亮显示
  • 远程配置管理：支持通过 IP 配置连接到远程设备，直接读取和写入标定文件
  • 格式校验：编辑过程中实时校验 JSON 格式正确性

技术实现

基于 Qt 的 Model/View 架构，自定义 QAbstractTableModel 实现 JSON 数据到表格的映射。使用 QStyledItemDelegate 实现自定义单元格编辑器。网络通信层使用 QTcpSocket 封装，支持异步读写。
