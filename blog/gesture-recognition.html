2026.05AI
本页索引

    项目概述

    本项目的目标是在 Android 平台上实现基于摄像头的手势识别功能，用于座舱内的非接触式交互控制。整体方案采用 NDK 调用 C++ 推理模块，在高通 8295 平台上部署 YOLO 模型。

    技术架构

    应用层通过 Android Camera2 API 获取帧数据，通过 JNI 传递到 Native 层。Native 层使用 OpenCV 进行预处理，然后调用 QNN 推理引擎执行 YOLO 模型。检测结果回传到 Java 层进行 UI 渲染和交互响应。

    高通 8295 平台适配

    基于官方 Demo 进行二次开发，将原本的 CPU 推理替换为 QNN 硬件加速推理。打通了 Camera 数据流到 QNN 推理链路的完整管线，实现了端侧高性能目标检测与标注。
