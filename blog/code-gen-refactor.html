座舱 C 代码生成工具重构

2026.05重构

痛苦的起点

座舱项目中有一份约 2 万行的 C 代码生成工具，最初由 AI 生成，结构混乱、耦合严重、可维护性极差。每次需求变更都需要工程师逐行修改生成逻辑，极其容易引入新问题。

重构策略

我们没有选择重写，而是采用渐进式重构。第一步是梳理现有逻辑，绘制模块依赖图；第二步是按功能拆分为独立模块；第三步是设计配置驱动的代码生成机制。

配置驱动设计

重新设计了基于 Excel 的配置驱动生成方案。将时序信息、步骤定义、类型映射等信息全部放在 Excel 配置表中，代码生成器负责解析配置并输出规范的 C 代码。

// Excel 配置示例
// 时序 | 步骤ID | 输入类型 | 输出类型 | 超时(ms)
// T1   | STEP_A | uint32   | float    | 100
// T1   | STEP_B | float    | bool     | 50
  • 系统扩展性大幅提升，新增功能只需修改 Excel 配置
  • 人工修改带来的错误率有效降低
  • 代码结构清晰，团队生产力明显改善
